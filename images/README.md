# Суреттер папкасы

Осы жерге "Bedroom R&B / Dark Romance / Chill Music" стиліндегі
эстетикалық суреттерді салыңыз (ұсынылған: ~10 немесе одан да көп).

- Қолдау көрсетілетін форматтар: `.jpg`, `.jpeg`, `.png`, `.webp`
- Бағдары (тік/жатық) маңызды емес — видео рендерінде FFmpeg әрқайсысын
  керекті форматқа (Shorts 9:16, ұзын видео 16:9) автоматты бейімдейді.
- Әр видео генерациясында осы папкадан кездейсоқ 1 сурет таңдалады.

Суреттерді қосқаннан кейін `README.md` файлын қалдыруға болады — ол
скрипт үшін кедергі жасамайды (тек `.jpg/.jpeg/.png/.webp` файлдары
ескеріледі).
