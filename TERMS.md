# Terms of Service — CrimsonRoom Auto-Pipeline

Last updated: 2026-09-05

CrimsonRoom is a personal, non-commercial automation project. It is a
Python pipeline, run via GitHub Actions, that generates video content
and uploads it to a single YouTube channel owned and operated by the
developer.
